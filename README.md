# System 2 Homepage (Next.js + Tailwind v4-ready)

## Local preview
npm i
npm run dev
# http://localhost:3000

## Deploy on Vercel
1) Push this folder to a GitHub repo.
2) In Vercel: Add New → Project → Import repo → Deploy.

## Domain
Add in Vercel → Settings → Domains, then set DNS:
- A @ → 76.76.21.21
- CNAME www → cname.vercel-dns.com.
